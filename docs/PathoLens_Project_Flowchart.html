Prediction: what class fits the whole tile?

The classifier gives one set of scores for the complete image. Its confidence is the highest softmax score; it is not calibrated for clinical decisions.

Explanation: where did the class score come from?

Class score→Grad-CAM map→Activation cutoff→Approximate boxes

The slider changes the heatmap activation cutoff. Lower values include more activated pixels; higher values keep only stronger activations.

How to read the visual outputs

Original image

The uploaded RGB image, shown for comparison. The model receives a resized copy; the original remains available for the display.

Grad-CAM heatmap

A rough map of image areas that influenced the selected class score. Brighter red areas mean stronger relative activation within this map, not a higher chance of disease.

Boxes

Connected high-activation areas are outlined on a copy of the original. Their coordinates are scaled to the original image size, but the regions are approximate.

Threshold clarity: the slider filters normalized Grad-CAM activation. It is not a confidence slider. This classifier produces no separate confidence scores for individual boxes.

Useful terms

Softmax score

Turns the model’s nine raw class scores into values that sum to 100%. The largest value is reported as confidence, but these values have not been calibrated for E2.

Grad-CAM

A technique that uses gradients inside the classifier to create a coarse, class-specific heatmap. It helps inspect the model; it does not prove why the prediction is correct.

Connected region

A group of neighboring heatmap pixels above the activation cutoff. The app outlines qualifying groups as approximate boxes.

What this app can and cannot tell you

It can

Classify a tile into one of nine PathMNIST tissue categories, show its class scores, and display a rough Grad-CAM explanation.

It does not detect lesions

The model was trained for image classification, not object detection or pixel-level segmentation. Its boxes are not lesion boundaries or validated findings.

It is not a diagnosis

This research and education tool is not clinically validated. Do not use its predictions to make medical decisions.

PathoLens uses a 50% PathMNIST pilot subset. The available evaluation does not establish patient- or slide-level independence or external clinical validity.
