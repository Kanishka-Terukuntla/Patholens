# Saved result files

- `experiment_comparison.md` — methods, selection rationale, test comparison, limitations.
- `test_experiment_summary.csv` — aggregate test metrics for E1–E4.
- `test_per_class_metrics.csv` — class-wise precision, recall, specificity, F1 and support for each experiment.
- `test_confusion_matrices_long.csv` — confusion counts for each true/predicted class pair.
- `validation_experiment_comparison.csv` — saved validation selection results.
- `epoch_metrics.csv` — epoch-level training and validation history.
- `winning_model_calibration_metrics.csv` and `winning_model_selective_metrics.csv` — calibration artifacts available for E1 only; not applied to E2.
