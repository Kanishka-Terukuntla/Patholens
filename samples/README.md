# Upload-ready sample images

One PNG from each class in the packaged 50% PathMNIST test subset. These are actual test samples exported from `data/test/test_images.npy`; filenames identify the saved class label. They are intended for checking the app's upload and display flow, not for unbiased model evaluation after the test set informed model selection.

The underlying MedMNIST dataset is distributed under CC BY 4.0. Refer to the official [MedMNIST data page](https://github.com/MedMNIST/MedMNIST#data-files) for data source and attribution details. PathMNIST is not intended for clinical use.
