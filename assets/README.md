# Figures

Saved figures from the 50% experiment run, grouped by purpose:

- `training_curves.png` — saved training/validation curves.
- `validation_vs_test_macro_f1.png` — validation selection metric alongside descriptive test metric.
- `test_per_class_f1_comparison.png` — test F1 by class and experiment.
- `E1_test_confusion_matrix.png` through `E4_test_confusion_matrix.png` — saved test confusion matrices.
- `eda_class_distribution.png` — class counts in the sampled dataset.

These are copied result artifacts; the app does not regenerate them.
